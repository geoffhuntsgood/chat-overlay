# Simple Twitch Chat Overlay

Want a simple browser source for your Twitch chat and emotes? Look no further! Just set up a browser source and point it to https://geoffhuntsgood.com/chat-overlay?channel={channel}&font={font}.

- Replace {channel} with the Twitch channel name you'd like to read chat from (default is my channel).
- Replace {font} with the font you'd like to use (currently limited, default is Jersey10). If you don't care about the font then just leave off the "&font={font}".

This is a read-only implementation - no bots, commands, or badges are included.
